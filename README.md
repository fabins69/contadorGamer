# 🎮Contador Gamer

Projeto desenvolvido em React Native com Expo.

---

# 📔 Preview do APP

O aplicativo posui:
* contador de pontos;
* botâo de aumentar;
* botão de diminuir;
* botão de resetar;
* interface estilo gamer.

---

# 👩‍💻 Tecnologias utilizadas

* React Native
* Expo
* JavaScript

--- 

# 🦮 Como executar o projeto

## 1. Clonar o repositório
```
git clone https://github.com/fabins69/contadorGamer.git
```

## 2. Entrar na pasta do projeto
```
cd contadorGamer
```

## 3. Instalar dependências
```
npm install
```

## 4. Rodar o projeto
```
npm start
```
